# Python Data Structures Assignment

This project demonstrates the use of basic Python data structures including:

- Lists
- Tuples
- Sets
- Dictionaries

The assignment is based on a small e-commerce product catalog.

## Tasks

### Task 1 - Product Collections

In this task, I worked with Python lists and tuples.

Operations performed:

- Created a list of products
- Accessed the second and last product
- Added new products using `append()`
- Created a tuple containing product name, price, and category
- Converted a tuple into a list
- Updated the product price
- Converted the list back into a tuple

### Task 2 - Categories Using Sets

In this task, I worked with Python sets.

Operations performed:

- Created a list of product categories
- Converted the list into a set to remove duplicates
- Added a duplicate category
- Added a new category
- Checked whether a category exists using the `in` operator
- Counted the total number of unique categories

### Task 3 - Product Price Dictionary

In this task, I worked with Python dictionaries.

Operations performed:

- Created a dictionary containing product prices
- Added a new product using `update()`
- Updated an existing product price
- Removed a product using `pop()`
- Calculated the average product price
- Found the maximum and minimum product prices
