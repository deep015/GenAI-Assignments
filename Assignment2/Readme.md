# GenAI Assignment 2 – Python Control Flow

This assignment focuses on practicing Python control flow concepts.

## Tasks

### Task 1: Discount Rules
- Take order amount as user input.
- Apply discount using `if / elif / else`.
- Calculate 5% tax and final amount.
- Handle invalid input using `try-except`.

## Task 2: Process Multiple Orders
- Process a list of orders using a `for` loop.
- Apply discount rules using `if / elif / else`.
- Calculate the final amount after discount.
- Calculate total revenue after discounts.

## Task 3: User Menu
- Create a menu using a `while` loop.
- Add order amounts to a list.
- Display orders and amounts after applying discounts.
- Use `break` to exit and `continue` for invalid input.

## Task 4: Product Categories
- Store products according to their categories.
- Find the category having the maximum number of products.
- Display the products from the maximum category.
- Practice lists, loops, and conditional statements.

## Concepts Used
- `if / elif / else`
- `for` loop
- `while` loop
- `break` and `continue`
- Lists
- Basic arithmetic
